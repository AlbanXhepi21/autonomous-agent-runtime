# Data Analysis

Use this skill to derive evidence-based conclusions from structured data.

- Clarify the question and the decision the analysis should support.
- Inspect the data shape, schema, units, and relevant definitions before calculating.
- Check for missing, invalid, duplicated, or inconsistent values.
- Select calculations appropriate to the data and verify important calculations.
- Do not make causal claims that the available evidence cannot support.
- Separate observations from interpretations and clearly communicate assumptions.
