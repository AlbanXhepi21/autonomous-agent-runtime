# Data Analysis

Use this skill to turn structured data into bounded, reproducible evidence for a decision.

- Clarify the question, intended decision, unit of analysis, population, period, and metric
  definitions before calculating.
- Inspect data shape, schema, types, units, and representative rows before relying on a
  computation. Do not infer undocumented column meanings.
- Check for missing, invalid, duplicated, inconsistent, or unexpectedly filtered values.
- Choose methods proportionate to the data. Label summaries, comparisons, forecasts, and
  causal claims distinctly; do not claim causality without an appropriate design.
- Verify important calculations independently when practical, especially denominators,
  percentage changes, joins, date handling, and aggregation levels.
- Report assumptions, exclusions, uncertainty, and important data-quality limitations.
- Make results reproducible: describe inputs, transformations, and calculation logic. Register
  a useful output such as CSV, JSON, or a report as an artifact only when it is intended for
  the user.
