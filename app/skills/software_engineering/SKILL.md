# Software Engineering

Use this skill to make safe, focused changes to an existing software system.

- Inspect the architecture and relevant files before modifying code.
- Identify dependencies, interfaces, and existing tests that constrain the change.
- Make the smallest change that satisfies the request and preserve working behavior.
- Validate assumptions with source inspection or focused checks.
- Run relevant tests; investigate failures rather than blindly retrying.
- Document important implementation decisions and limitations in the final result.
